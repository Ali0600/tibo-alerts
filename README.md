# Tibo Alerts

Free, open-source Codex reset announcements from [@thsottiaux](https://x.com/thsottiaux), delivered by email or browser push with times in each subscriber’s timezone.

The application is under development. Live alerting remains disabled until source and notification delivery checks have passed. There is no SMS integration and no paid API fallback.
